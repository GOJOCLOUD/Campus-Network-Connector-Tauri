# 模拟输入 · Tauri 版 —— 项目记忆

> 这份文档记的是**当前状态**。历史沿革见 [历史交接快照.md](历史交接快照.md)。
> 分支边界与平台范围见 [两条发布线.md](两条发布线.md)（接手前必读）。
>
> ⚠️ **这份文档以前是 Electron 项目的副本**，2026-10-24 才重写成 Tauri 线的真实情况。
> 如果你在别处看到"Electron + React""`main.js`""DMG""不再往 GitHub 推送"这些说法，
> 那是**旧的、错的**——本仓库是 Tauri 版，没有 `main.js`/`preload.js`/`.node` 插件。

## 这是什么

桌面应用「模拟输入」的 **Tauri 版**：模拟鼠标点击与键盘输入，用于校园网自动登录等场景。

同一个产品的另一个正式版本是 **Electron 版**，在独立仓库
[`Campus-Network-Connector-Electron`](https://github.com/GOJOCLOUD/Campus-Network-Connector-Electron)。
两者**同等优先**（不是"新的取代旧的"），**互不回流**。

## 技术栈与架构

- **Tauri 2 + React（Vite）+ Rust**（`tauri-app/src-tauri/`）
- **没有 `.node` 原生插件**：macOS 走 CoreGraphics / Carbon TIS，Windows 走 Win32 SendInput，
  都是 Rust 直接调 ⇒ **不需要 node-gyp、不需要 asarUnpack**
- 前端在 `src/` → 产物 `dist/` → Tauri 打进应用（`frontendDist: "../../dist"`）
- Safari 复制修复走 Apple Events，**只有 macOS 有**（功能注册表按 `platforms` 字段过滤）

## 分支

| 平台 | 分支 | 产物 | 打包命令 | CI |
| --- | --- | --- | --- | --- |
| macOS (arm64) | `mac` | `.app` → zip | `npm run tauri:build:mac` | `build-tauri-macos.yml`（macos-latest） |
| Windows (x64) | `win` | NSIS exe | `npm run tauri:build:win` | `build-tauri-windows.yml`（windows-2022） |

**本机不打包 Windows**（要 `llvm-rc` 与 Windows SDK）——Windows 产物一律走云端 CI。
本机只保留 `x86_64-pc-windows-msvc` 这个 Rust 目标做类型检查：
`./tools/windows-check.sh`（里面用的 `tools/windows-check-rc-stub.sh` 是替身脚本，不是真工具）。

## 门禁（跑不过就不发包）

| 门禁 | 位置 | 盯什么 |
| --- | --- | --- |
| frame-bridge 回归 | `tools/verify/verify-frame-bridge.cjs` | 站点换掉嵌套 iframe 后，映射还能不能送到新那层 |
| 页面守卫回归 | `tools/verify/verify-page-guard.cjs` | 换题后新作用域会不会被发现、映射会不会真的到页面 |
| 界面回归 | `tools/verify/verify-panel-transition.cjs`、`verify-recording-ui.cjs` | 换页时底下不许有横向滚动条；录制能单条删除 |
| 平台界面自检 | `tools/verify/verify-ui-platforms.cjs` | 两个平台各自的界面 |
| Rust 单测 | `cargo test --lib`（`tauri-app/src-tauri`，**37 条**） | 守卫上报字段名、注入脚本字面量、混淆字体能否整份还原 |
| 产物自检 | `tools/verify/verify-package.cjs` / `verify-package-win.cjs` | 运行时资源齐不齐（**尤其字形参考库 `glyph-db-48.crdb.gz`**——漏了不报错，只是「装上之后 Safari 复制修复静默失效」） |
| 交付自检 | `tools/lab/package-deliverables.cjs` | **打包前先自检，验不过就不出包**——桌面 zip 绕过 CI，交付路径自己也得有门禁 |

## 交付到桌面

```bash
node tools/lab/package-deliverables.cjs   # 必须在本仓库跑（脚本会自定位仓库）
```

产出桌面两个包：`模拟输入-mac-arm64.zip`（两个 .app）与 `模拟输入-Windows-全部.zip`（两个 exe，
Windows 安装程序从 CI 的 release 取）。交付脚本**打包前会先跑产物自检**。

## 提交与推送

**会推 GitHub**：`mac` / `win` 各自推各自 —— CI 靠 push 触发，产物作为 release 附件发布
（tag 形如 `mac-<run_id>` / `win-tauri-<run_id>`）。
提交只 `git add <具体路径>`，不用 `-A`；删东西要单独授权。

## 与 Electron 版的关系

- **独立仓库、独立 CI、不互相回流**。要搬就**显式搬**，并在提交说明里写清搬的是什么。
- 共用的只有三样：界面骨架（Stepper + panels 的结构）、激活授权那套纯 JS 逻辑（tweetnacl）、
  `tools/verify/verify-ui-platforms.cjs`。
- 其余——运行时、原生实现、打包配置、CI、依赖、文档措辞——**各自分开**。
- 界面层另有一条硬规矩：**ADR-0013**——界面层**逐字照搬** Electron 版，
  差异只允许「Tauri 必需」或「已定产品差异」。

## 已知问题 / 待办

- `tauri.windows.conf.json` 是 Windows 专用的**覆盖配置**（`.ico` 图标、无边框窗口、NSIS
  `currentUser`）。**它历史上没接进任何构建命令** ⇒ Windows 包是用 mac 配置打出来的
  （图标是 `.icns`、窗口带着 macOS 专属的标题栏设置）。2026-10-24 起接上。
- macOS 上合成点击/键入要「辅助功能」权限；没权限**直接报错**，不再"显示成功却什么都没发生"。
- Safari 复制修复还要 Safari 侧开 Apple Events（见 `docs/05-运维/安装指南-macOS-Safari.md`）。
- 录制排除矩形的真机自检（`control:1 / excluded:0`）**仍无结论**。
- **Windows 线从未在真 Windows 机器上跑过**；CI 只能证明可编译、单测通过，真机行为未验证。
- Windows 线 2026-10-24 起在做「与 macOS 线行为对齐」（快捷键 ⌃S/⌃D + latch、换页滚动条修复、
  界面自检补齐），见该分支的 ADR。
