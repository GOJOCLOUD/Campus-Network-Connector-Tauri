## 五、**还没有**验到的(不糊弄)

- **真超星端到端**:真页面上的混淆字体 → 选中题干 → Ctrl+C → 剪贴板里是**明文**。
  这一步**只能真人做**(扫码、选题、拖选、按键),机器替代不了
  (注入的按键进不了系统输入队列,前台又被管理员权限的窗口占着)。
- **钩子在微信里的优先级**:在微信里按 ⌃D 能不能压过微信。
- **Electron 线的 ⌃D 真机按键**(Tauri 线已验过)。
- **Chrome 路径**(只测了 Edge)。
- **iframe 子框架里的题目**。
- **mac 线键位仍不一致**(那边机器负责;本仓只读不动 mac 分支)。

## 六、怎么自己验一遍(用户视角)

1. 装上其中一个安装包(两个都行,功能一样,只是技术栈不同);
2. 启动软件 → 最后一页(键盘输入那一页)最上面 → 打开「浏览器复制修复」;
3. 软件会打开**它自己的** Edge 窗口 —— **在那个窗口里**扫码登录超星、
   进题、拖选题干、Ctrl+C ⇒ 复制出来就是**明文**;
4. 「读剪贴板并键入」= **⌃D**(⌃⇧D 是容错别名)。
   软件开着的时候别的软件收不到 ⌃D(Edge 的收藏夹、VS Code 的选中下一处、Excel 的向下填充);
   软件**也**装了低级键盘钩子,所以微信那类用钩子抢键的软件压不过我们 ——
   但 Windows 是「**后装的钩子先被调用**」⇒ **把本软件放在那些软件之后启动**才稳赢。
