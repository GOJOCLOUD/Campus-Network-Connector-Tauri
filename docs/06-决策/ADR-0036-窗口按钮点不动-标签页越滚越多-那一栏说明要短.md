# ADR-0036:右上角按钮点不动、浏览器标签页越滚越多、那一栏说明要短

- 状态:**已定**
- 日期:2026-10-27
- 用户原话(2026-10-27 20:26,针对 Electron 版;根因同源):
  > 「没有丝毫修复，至少electron版本是这样的，右上角的缩小，最小化按钮，以及关闭按钮，完全就无法生效，然后打开浏览器这一这个界面说明太详细了，看起来乱七八糟的，不够简短，然后很严重的问题是一旦点击这个东西。它就会打开，不断的拉起浏览器，然后浏览器里面的页面超级多，而且这个浏览器根本就是无法使用的状态」
- 相关:ADR-0034(反反复复拉起浏览器)、ADR-0035(两个版本一眼分清)、ADR-0032(先找再起)
- 谱系:Electron 侧是**同一条决策**的 ADR-0026,两边行为一致。
  **别照抄 Electron 那边的 CSS 说法** —— 两边机制不同(见下)。

---

## 一、三个问题,三个根因

### 1. 右上角「最小化 / 叉叉」点不动 —— **拖拽区把真实鼠标点击吃了**(与 Electron 同源)

Electron 线在真机上抓到了确凿证据(见 Electron 仓 ADR-0026 第一节):
按钮的 React 逻辑、IPC、命中测试**全都是好的**,唯独**真实鼠标点击**进不去。

**Tauri 线的机制与 Electron 不同**:

| | Electron | Tauri |
| --- | --- | --- |
| 标记 | CSS `-webkit-app-region: drag / no-drag` | 属性 `data-tauri-drag-region="deep" / "false"` |
| 谁判定「这次按下要不要拖窗口」 | **浏览器进程**(Chromium) | **渲染进程**:从被点到的元素往上找**最近一个**带该属性的祖先 |

⇒ Tauri 里,根容器 `App.jsx` 上是 `data-tauri-drag-region="deep"`(整窗都是拖拽区),
而右上角按钮那个容器(`Stepper.jsx` 的 `corner`)**自己没有**这个属性
⇒ `closest()` 一路往上找到根容器 ⇒ 判定成「拖窗口」⇒ **点击根本不会触发按钮**。

⇒ **两处必须显式写 `data-tauri-drag-region="false"`**:

1. **右上角按钮容器**(`Stepper.jsx` 的 `corner`)
2. **内容区**(`Stepper.jsx` 的 `StepContentWrapper`)
   —— 不然内容区里的「开启 / 关闭」「输入框」在 Tauri 里也是点不动的
   (Electron 那边靠 `.app-nodrag` 挡住了,Tauri 那边**没有等价物**)

另外「步骤圈 + 进度线」那一行的**矩形横跨整张卡片**、右上角正好压在窗口按钮上
⇒ 这一行**不再声明拖拽区**(根容器的拖拽区已经覆盖整窗,那一行照样能拖)。

### 2. 点开关就**不断拉起浏览器、页面越积越多** —— `--restore-last-session` 的指数级放大

Electron 线在真机上复现到了:标签页 `10 → 14 → 17 → 21 → 22`,
其中 **21 个是 `about:blank`**。根因三条:

1. **`--restore-last-session`**(根因):每次启动都把**上一次会话**的标签页全恢复出来,
   而上一次会话里又装着上次恢复出来的那些 ⇒ 标签页**每次启动多一批**。
2. 标签页一多 ⇒ 浏览器启动变慢 ⇒ 调试端口迟迟不开 ⇒ 被判定成「起不来」。
3. **连不上 CDP 不计失败次数** ⇒ 「起不来上限(3 次)」形同虚设
   ⇒ 每 4 秒重试一次、每次都再拉起一个浏览器。

**决策**(四条一起改):

| # | 改动 | 为什么 |
| --- | --- | --- |
| a | **去掉 `--restore-last-session`** | 标签页不再滚雪球。**不影响登录**——cookie / 密码在 profile 里,照样有效 |
| b | `CdpClient::connect()` 失败**也计入** `launch_failures` | 让「起不来上限」真的生效 |
| c | 已经有浏览器在跑、只是暂时连不上 ⇒ **不再起新的** | 同 profile 再起一个 = Chromium 的「转发启动」:只会给已经在跑的那个**再开一个标签页** |
| d | 扫进程时**同时报「用了本 profile 但没带调试端口」的进程数** | 光看端口会漏掉那种 ⇒ 照样会转发启动 ⇒ 照样多开标签页 |

### 3. 那一栏说明太长

`description`(21 字)+ `hint`(57 字)+「浏览器已关闭」那一行(20 字)
叠在一起 ⇒ 那一栏变成三大段密密麻麻的字 ⇒ 用户原话「看起来乱七八糟的」。

**决策**:界面上只留**必须当下知道的一句**,细节挪到文档里
(与 Electron 版**逐字一致**,两个 Windows 版本界面对得上):

| 位置 | 改后 |
| --- | --- |
| 功能说明 | **还原网页里被混淆的文字** |
| 开关打开时的提示 | **请在本软件开的 Edge 窗口里上网、答题** |
| 「浏览器已关闭」 | **浏览器已关闭（不会自动重开）** |

⚠️ **只改 Windows 线那一份**:macOS 的「Safari 复制修复」那条文案**一个字不动**
(mac 线由另一台机器负责)。
