# ADR-0027:Windows 线不占用系统默认快捷键 + 关窗口不退出 + 右上角三个按钮 + 托盘常驻

- 状态:**已定**(用户 2026-10-24 明确指令)
- 日期:2026-10-24
- 相关:ADR-0012(平台功能范围)、ADR-0013(界面层逐字照搬 Electron)、ADR-0025(Windows 线与 macOS 线行为对齐)、ADR-0026(Windows 线不保留「默认执行」界面)
- 性质:**拍板 ADR-0026 里挂着的「⌃S 待拍板」那条**,并定下 Windows 线的窗口生命周期。

## 背景

2026-10-24 用户在 **Windows 版**上提了三件事(原话):

1. 「Windows 电脑上 tmd Ctrl 加 D 是系统默认的按钮,我不能设置为快捷键,不然他直接把软件退出了」
2. 「你不能点叉,他就直接完全退出了,这个他要在后台挂着,功能依然生效呀」
3. 「或者你把它右上角做一个三个按钮,就是最大化最小化或者说直接关掉,别只留一个关掉的按钮」

三件事指向同一件事:**这个 app 在 Windows 上不该抢系统的键,也不该一关就没。**

---

## 决策一:Windows 线一个系统全局键都不占

### 背景

- **⌃D 是 Windows 的系统默认键**。我们用系统的全局热键(`RegisterHotKey` /
  Electron 的 `globalShortcut.register`)把它抢过来 ⇒ 用户在**自己常用的软件**里按 ⌃D,
  那个软件/系统对话框会**直接被关掉**。用户说的「不然他直接把软件退出了」就是这个。
- **⌃S 同为系统默认键**(「保存」)。而且它驱动的「默认执行(回放)」在 Windows 上
  **已经没有界面了**(ADR-0026 决策一)⇒ 留着它就是一个**没有入口的隐藏功能**:
  用户在自己窗口里随手按一下 ⌃S,屏幕上就会开始**自己动鼠标**。

### 决策

**Windows 线不注册任何全局快捷键。**

| 层 | 之前 | 之后 |
| --- | --- | --- |
| 系统全局热键 | 注册 ⌃S / ⌃D | **一个都不注册** |
| 窗口内 keydown | 拦 ⌃S(⌃D 原本已禁) | **不拦** —— ⌃S / ⌃D 就是普通按键 |
| Control 观察线程 | 每 20ms 轮询 `GetAsyncKeyState(VK_CONTROL)` | **不启动**(它只服务于全局键的 latch) |
| 「读剪贴板并键入」的入口 | ⌃D 全局键 | 「键盘输入」页的**按钮**(见决策四) |

### 实现:留成**显式开关**,而不是把代码删掉

删掉注册逻辑,以后就没人知道「这里本来有过全局键」;而且想加回来时得从头写。
所以留了两个一眼能看出意图的开关:

| 实现 | 开关 | 位置 |
| --- | --- | --- |
| Tauri | `global_shortcut_keys()` 返回空 `Vec` | `tauri-app/src-tauri/src/lib.rs` |
| Tauri | `HOTKEY_OBSERVER_ENABLED = false` | 同上 |
| Electron | `GLOBAL_SHORTCUTS_ENABLED = false` | `main.js` |

**诊断里多了一栏** `shortcuts.globalShortcutsEnabled`(Tauri)/
`globalShortcutsEnabled`(Electron)= `false` ⇒ 排查时能分清
「**按政策不注册**」和「**注册失败**」。这正是旧文档里反复说不清的那个坑。

### 门禁

- Rust 单测 `shortcut_tests::Windows线不注册任何全局快捷键`:
  清单必须是空的,且观察器开关必须是关的。
- 界面门禁 `verify-ui-platforms.cjs` 的**源码级断言**(界面上看不出系统里注册了哪些键):
  查的是**开关常量**,不是「调用点消失」—— 注册那条路还在,被开关挡着。

## 决策二:关窗口 = 藏起来,进程留着(托盘常驻)

### 背景

「点叉他就直接完全退出了」= 把 app **关掉了**,不是「收起来」。
用户要的是**后台挂着、功能依然生效**。

### 决策

| 动作 | 结果 |
| --- | --- |
| 右上角「关闭」按钮 | **隐藏窗口**,进程留着 |
| 系统级关闭(Alt+F4 / 任务栏右键→关闭窗口) | **同样只隐藏**,不退出 |
| 左键点托盘图标 | 把窗口叫回来 |
| 托盘右键菜单 →「显示窗口」 | 把窗口叫回来 |
| 托盘右键菜单 →「退出程序」 | **彻底退出**进程 |
| 再运行一次程序 | 单实例回调 → 把窗口叫回来 |

系统级关闭**也只隐藏**,是为了跟 macOS 的红绿灯**同口径**
(关窗口 ≠ 退出 App)。于是**彻底退出的唯一入口是托盘菜单的「退出程序」**。

### 为什么必须有托盘

Windows 上窗口一藏,**任务栏就没有图标了** —— 没有托盘,这个 app **再也找不回来**
(只剩「再运行一次程序」那条路,而用户不一定知道 exe 在哪)。

### 实现

| 框架 | 用的什么 | 新增依赖 |
| --- | --- | --- |
| Tauri | `tauri::tray::TrayIconBuilder`(Tauri v2 **内置**) | **无新 crate** —— 只给 `tauri` 加 `tray-icon` feature |
| Electron | `Tray`(Electron **内置**) | 无 |

> **更正一处先前的判断**:本轮开工前定的方案是「不做托盘」,理由是
> 「本机 crates.io 不可达 ⇒ 拉不到 `tauri-plugin-tray-icon`」。
> 实际查下来是:**插件确实拉不到**,但 **Tauri v2 自带托盘 API**,
> 它只要给现有的 `tauri` 依赖加一个 **feature**(`tray-icon`),
> 而它拉的两个 crate(`tray-icon 0.25` / `muda 0.20`)**本机 cargo 缓存里就有** ⇒
> 离线可构建。⇒ 决定做托盘。
> (证据:`cargo check --offline` 通过;`Cargo.lock` 里多了 `tray-icon` / `muda` 两项。)

### 托盘建不起来**不能拖垮 app**

托盘只是「找回窗口」的**便利**,不是「后台活着」的必要条件:
窗口只是被**隐藏**,进程照样活着,常驻能力都还在。
所以任何一步出错都只是**不装托盘**,并把原因写进日志(`[tray] ...`),
app 照常启动。

## 决策三:右上角三个自绘按钮

**最小化 / 最大化(再点一次还原)/ 关闭。**

- Windows 是**无边框窗口**(Tauri `decorations:false` / Electron `frame:false`),
  所以这三个是**页面自绘**的;macOS 仍用**原生红绿灯**,不变。
- 「最大化」是**切换**:`isMaximized() ? unmaximize() : maximize()`
  (与 Electron 版 `window:maximize` 同口径)。
- **最大化时不做「窗口贴合内容」**(`window_fit_to_content` 直接返回):
  这时窗口尺寸是系统定的,再 `set_size` 会把最大化状态顶掉,
  表现出来就是「点了最大化,窗口又弹回去」。
- 三个按钮挂在 `Stepper` 的 `corner` 位置(`app-nodrag`,不触发拖窗)。

---

## 决策四:「读剪贴板并键入」搬到界面按钮

⌃D 撤掉后,这个能力**不能丢**(它是真的功能)。

- 入口:**「键盘输入」页多一个按钮**「从剪贴板读入并键入」。
- 读剪贴板走**原生**通道(`cnc.clipboardReadText()` → Win32 `OpenClipboard` /
  Electron `clipboard`),**不用** `navigator.clipboard.readText()` ——
  WebView2 里那个会因为焦点/权限直接失败。
- 键入走 `cnc.pinyinInput(text, 0, false)`(与原来 ⌃D 那条同一条路)。

## 验收

- **界面**(Windows,`tools/verify/verify-ui-platforms.cjs`):
  - 右上角**有 3 个按钮**,且依次是「最小化 / 最大化 / 关闭」;
  - 点这三个按钮,分别调的是 `minimize` / `maximize` / `hide`;
  - **「关闭」不调 `quit`**(那才是「直接退出」);
  - 「键盘输入」页**有**「从剪贴板读入并键入」按钮,且**真把剪贴板里的字送进键入通道**。
- **原生**:`cargo test --lib` —— 含
  `shortcut_tests::Windows线不注册任何全局快捷键`。
- **源码级**:注册清单是空的 / 观察器开关是关的(Tauri 与 Electron 各一条断言)。
- **macOS 线不变**:界面仍是 4 步、仍用原生红绿灯、仍注册 ⌃S / ⌃D。
- 两线各跑各的自检,各发各的包;**一边的绿不替另一边背书**。
- ⚠️ **Windows 真机行为仍未经真机验证**(本仓库的验证环境是 macOS)。
  CI 只证明「编得过 + 门禁过」。托盘图标、隐藏窗口、真正退出这三条,
  都要在 Windows 真机上过一遍。

---

## 范围与没做的

- 本 ADR **只改 Windows 线**(`win` 分支)。macOS 线一行没动。
- **Windows 上不再有任何全局快捷键**。如果以后要加,必须是**不与系统默认键冲突**的组合
  (键位由用户拍板;用户此前明确拒绝过 Shift 组合)。
- 「读剪贴板并键入」这个按钮**只在 Windows 线出现**(macOS 线的 ⌃D 还在,不需要)。
