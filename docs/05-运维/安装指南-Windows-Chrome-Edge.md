# Windows 11 · Chrome / Edge 安装指南

适用：Windows 11 上的 Google Chrome 与 Microsoft Edge（两者都是 Chromium 内核）。

> **2026-10-26 起形态变了**：Windows 线**不再需要装任何扩展**。
> 桌面程序**自己起一个浏览器**并用 CDP 把守卫注进去 —— 详见下面第 0 节与
> [ADR-0030](../06-决策/ADR-0030-Windows线改用软件自起浏览器加CDP注入守卫.md)。

---

## 0. 产品用户：装上程序，拨一下开关，完事

> 这一节给**产品用户**（已经拿到安装包的人）；
> 下面第 1 节起是给**开发者**的。

Windows 上的「把密文还原成明文」现在由**桌面程序自己起浏览器 + 注入守卫**提供。

**步骤**

1. 装上「模拟输入」（Tauri 版）。
2. 打开程序 → 走到**最后一页**（键盘输入那一页）。
3. 页面最上面有一个开关：**「浏览器复制修复」** —— 和 Mac 上的「Safari 复制修复」
   **长得一模一样**。
4. 点「开启」。

**程序会打开一个自己的 Edge 窗口。**
请**在这个窗口里**上网、答题、复制 —— 守卫只装在这个窗口里。
关掉它没关系，程序会重新打开。

- **要不要装扩展？** **不用**（Windows 线已不用扩展，见 ADR-0030）。
- **要不要开「开发者模式」？** **不用**。
- **要不要重启浏览器？** **不用**。
- **要不要管理员权限？** **不用**。

**首次使用**：在那个 Edge 窗口里**扫码登录一次**超星（之后就记住了）。
用户确认过：重新登录**只需扫码**。

**关掉**：把那个开关拨回「关闭」即可（程序停止接管；
那个 Edge 窗口会留在那儿，它是你的窗口了，想关自己关）。

**怎么确认生效**

- 程序里那个开关的状态文字应是「**已接管**」；
  如果是「已开启」但没接管，下面会有一行**失败原因**。
- 在网页上选中题干按 `Ctrl+C`，粘出来的应是**明文**（不是乱码）。

**出问题了看这里** → `docs/05-运维/故障排查.md` 的
→「Windows 上「把密文还原成明文」不生效」那一节。

## 1. 运行时产物(开发者)

页面守卫、帧桥与字形参考库**已经提交进仓库**，构建时会被**嵌进主程序二进制**
（Tauri 侧不构建 TS，直接用这几份）：

```
tauri-app/src-tauri/resources/
├── page-guard.js          # 注入网页的页面守卫（document_start 注入）
├── frame-bridge.js        # 顶层桥（把同源 iframe 串起来）
└── glyph-db-48.crdb.gz   # 参考字形库（GBK 全集，随包分发，不联网）
```

字形参考库**必须从应用包里读**（`resource_dir`），不能用构建机上的路径 ——
打成包发到别的机器上构建机路径就不存在了（2026-10-22 踩过这个坑）。

## 2. 跑一遍端到端门禁(开发者)

```bash
cd tauri-app/src-tauri
cargo test --test cdp_copy_repair -- --nocapture
```

这条门禁**真起一个 Edge**：注入守卫 → 真字形识别 → 下发映射 →
合成 `Ctrl+C` → 断言**系统剪贴板**里是明文。Windows CI 上也在跑它
（跑不过就不发包）。

## 3. 自测页(开发者)

仓库自带夹具页：`src/features/safari-repair/test/fixtures/obfuscated.html`
（DOM 里是密文，混淆字体把它画成正常句子）。

正确明文应为「人工智能正在改变世界科技」。

## 4. 卸载

- 程序里把「浏览器复制修复」开关拨回「关闭」。
- 本软件开的那个 Edge 窗口：直接关掉即可；它的 profile 在
  `%APPDATA%\com.gojocloud.campus-network-connector.tauri\browser-profile`
  （删掉它 = 连登录态一起清掉）。
